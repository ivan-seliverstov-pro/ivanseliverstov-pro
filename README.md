# ivanseliverstov.pro

Персональный сайт-портфолио. Одна страница: обо мне, навыки, клиенты, проекты,
рекомендации, ответы на частые вопросы, контакты.

Сделан на Next.js и React, собирается в статические файлы.

## Команды

```bash
bun install    # установить зависимости
bun run dev    # запустить локально на http://localhost:3000
bun run build  # собрать сайт в папку out
```

## Контент

Тексты и изображения сайта хранятся в отдельном репозитории и подключаются к проекту
как папка `public`. Без неё сборка не запустится и подскажет, что делать.
